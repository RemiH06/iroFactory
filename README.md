## :art: iroFactory

### General Description

A personal collection of 12 self-contained HTML design themes for project documentation. Each theme ships as a single file with its own animated background, color system, typography, and semantic tokens. Intended as documentation skins for personal projects spanning algorithms, data science, creative writing, travel, music, embedded systems, and more.

```diff
- These themes are for personal documentation use, not installable UI libraries.
- All files are self-contained. No build step or package manager required.
```

## Themes

| Icon | Name | Font | Description |
|------|------|------|-------------|
| ♫ | **disco** | Plus Jakarta Sans | App and UX design system. Semantic palette (tomato, indigo, mint, mustard, lilac, peach, sky) with asanoha geometric background and floating ambient lights. For frontend work and component documentation. |
| ◼ | **metro** | Space Mono + DM Sans | Technical writing and developer tooling. Traffic-light semantic trio with an animated node-graph background in red, yellow, and green. For algorithm notebooks and code tool documentation. |
| ⬡ | **sherry** | JetBrains Mono | Full-neon vaporwave. Organic triangle tessellation that flashes in seven neon colors, with optional CRT scanlines. For algorithm implementations, scripts, and developer utilities. |
| ◈ | **elixir** | Iosevka | Cold analytical theme for ML and data science. Neural graph background with nodes that permanently change color as signal pulses reach them. For model documentation and statistical notebooks. |
| λ | **lambda** | Cormorant Garamond + Fira Code | Chalkboard theme for mathematics. Light mode is a white board, dark mode is green slate. Background objects are formulas and diagrams in double-stroke chalk style. For proofs, academic papers, and lecture notes. |
| ▦ | **ludus** | Righteous + Fira Code | Carnival theme with two faces: a bright pastel fair by day and a circus tent interior by night, with crimson and gold curtains, a bichomatic checkerboard, and gold dust particles. For game development and creative project logs. |
| ✦ | **tarot** | Cinzel + Josefin Sans | Art deco with gold, crimson, and the four card suits. Seven types of geometric ornament tile the background. Tarot cards float upward through the scene. For personal writing and journaling. |
| ◫ | **bookworm** | Libre Baskerville + Fira Code | Forest theme in four layers: isometric triangle grid, komorebi light sources, SVG wood stencil with circular cutouts, and falling leaves or rain. For reading logs and literary documentation. |
| ☼ | **apolo** | Cinzel + Fira Code | Grecian theme framed by Ionic columns with rosettes. Petals drift through a sky of Aegean blue or Attic sunset. Columns are drawn fully in SVG with entasis, fluting, and volutes. For music notes, poetry, and creative arts documentation. |
| ➣ | **odysseus** | IM Fell English + Fira Code | A physical map on a wooden desk, tilted at a random angle each load. Compass with trembling needle, inkwell, and quill placed at random positions. Semantic tokens (route, must, wonder, fey, visited, unvisited) map journey annotations. For travel logs and geographic documentation. |
| 〰 | **shui** | Recursive (CASL 1) | Water in two zones. Pelagic mode shows Caribbean turquoise with a single wide sunbeam and rising bubbles. Abyssal mode is nearly black with bioluminescent particles rising in violet, rose, cyan, and green. For database schemas and data pipeline documentation. |
| ⚙ | **forge** | Azeret Mono | Industrial theme in two states: active foundry with lava descending from both sides and sparks rising from the floor; or cold workshop with electric arc flashes and three oscilloscope traces in green, crimson, and red. For firmware documentation and robotics project logs. |
