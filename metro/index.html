Documentación con señalética de metro

La página solo compone piezas compartidas de iroFactory, sin dependencias más allá de las fuentes. El fondo es una cuadrícula con nodos que flotan y se conectan entre sí, y la cuadrícula se ilumina bajo el cursor.

Las secciones de abajo se recorren desde el dock: cada ícono es una estación, y cada panel se carga la primera vez que se visita.

# Ejemplo de uso
import metro_theme

def setup():
    theme = metro_theme.getTheme()  # 'dark' | 'light'
    colors = {
        'accent': '#00e5a0',
        'danger': '#ff4560',
        'value':  42,
    }
    return colors
