§2Señales

Acento

Notas de arquitectura. El sistema corre sobre metal desnudo.

OK

Firmware flasheado correctamente. El MCU responde al ping.

Warn

Temperatura del core al 87%. Activar ventilador secundario.

Danger

Stack overflow en IRQ_Handler. El sistema se reinició.

Voltage

Rieles de 3.3 V y 12 V, ambos dentro de tolerancia ±5%.

Signal

PWM a 50 kHz. Duty cycle 72%. Osciloscopio confirmado.

Current

Consumo en idle 180 mA. En carga máxima 2.4 A.

Core

ARM Cortex-M4 a 168 MHz. FPU habilitada. Caché L1 activa.

Interrupt

IRQ prioridad 0. Non-maskable. El handler debe ser breve.

Flux

Campo del motor a pasos. 200 pasos por revolución.

Ground

GND común a todos los módulos. Nunca flotante.

Código

// ISR del temporizador principal
void TIM2_IRQHandler(void) {
  if (TIM2->SR & TIM_SR_UIF) {
    TIM2->SR &= ~TIM_SR_UIF;  // limpia la bandera
    pwm_duty = pid_update(setpoint, adc_read(0));
    set_pwm(pwm_duty);
  }
}

uint16_t adc_read(uint8_t ch) {
  ADC1->SQR3 = ch;
  ADC1->CR2 |= ADC_CR2_SWSTART;
  while (!(ADC1->SR & ADC_SR_EOC));
  return ADC1->DR;
}

Firmware pipeline

0x00

Reset handler

Inicializar el stack pointer. Copiar .data de Flash a RAM. Limpiar .bss.

0x01

HAL Init

PLL a 168 MHz. Clocks de periféricos. Latencia de Flash 5.

0x02

Periféricos

UART2 a 115200. ADC1 continuo. TIM2 PWM. I2C1 para sensores.

0x03

Main loop

while(1) · procesar la cola de eventos. WFI si está ocioso. Watchdog cada 500 ms.
