// ISR del temporizador principal
void TIM2_IRQHandler(void) {
  if (TIM2->SR & TIM_SR_UIF) {
    TIM2->SR &= ~TIM_SR_UIF;  // clear flag
    pwm_duty = pid_update(
      setpoint, adc_read(0)
    );
    set_pwm(pwm_duty);
  }
}

uint16_t adc_read(uint8_t ch) {
  ADC1->SQR3 = ch;
  ADC1->CR2 |= ADC_CR2_SWSTART;
  while (!(ADC1->SR & ADC_SR_EOC));
  return ADC1->DR;
}

Firmware Pipeline

0x00

Reset handler

Inicializar stack pointer. Copiar .data de Flash a RAM. Limpiar .bss.

0x01

HAL Init

Configurar PLL a 168MHz. Habilitar clocks de periféricos. Flash latency 5.

0x02

Periféricos

UART2 @115200. ADC1 continuo. TIM2 PWM. I2C1 para sensores.

0x03

Main loop

while(1) — procesar cola de eventos. WFI si idle. Watchdog feed cada 500ms.
