Callouts

Acento (default)

Notas generales de la aplicación, referencias de diseño y documentación.

OK · Mint

Acción completada. El usuario finalizó el flujo exitosamente.

Warn · Mustard

Atención requerida. Revisar configuración antes de continuar.

Danger

Error crítico. La acción no pudo completarse.

New · Tomato

Elemento nuevo disponible. Sin interacción previa del usuario.

Active · Indigo

Seleccionado o en uso. Estado de interacción activa.

Done · Mint

Revisado y marcado como completado por el usuario.

Indigo

Información del sistema. Navegación y acciones principales.

Mustard

Estadísticas y métricas de uso. Datos de engagement.

Lila

Funciones premium o experimentales de la app.

Sky

Contenido informativo. Tooltips y ayuda contextual.

Rose

Elementos favoritos o destacados por el usuario.

Peach

Notificaciones suaves. Recordatorios no críticos.

Gray

Contenido archivado o en segundo plano.

Código

Inline: toggleTheme() alterna entre modo claro y oscuro.

// Vista de detalle de lugar · tacology
struct PlaceDetailView: View {
    let place: Place

    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            RatingBadge(score: place.rating)
            Text(place.name)
                .font(.title2.bold())
            TagRow(tags: place.tags)  // ← badges de disco
        }
    }
}
