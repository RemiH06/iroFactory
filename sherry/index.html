Inline: crt off en la terminal apaga las scanlines.

# sherry: build anything
class Artefacto:
    def __init__(self, materiales):
        self.core   = materiales[0]
        self.shield = "basura reutilizada"
        self.online = True

    def activar(self):
        return f"[SYS] {self.core} online · shield: {self.shield}"

sherry-tri

Un juguete de línea de comandos: cualquier foto, convertida en triángulos que brillan.

Instalar

pipx install sherry-tri
sherry-tri --version

Uso

sherry-tri toma una imagen y la convierte en un mosaico de triángulos neón listo para fondo de pantalla. Marca opciones en la referencia y el comando se arma solo.
